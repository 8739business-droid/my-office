# my-office とは

my-office は、Claude Code の中に「自分だけの小さなオフィス」を作るプラグインです。
窓口になるのは、大阪弁で話す秘書の **ショー** です。

```
あなた
  └─ 秘書ショー(窓口)
       ├─ 秘書室   … TODO・メモ・壁打ち(最初からある)
       ├─ リサーチ … 担当ミオ(必要になったら増える)
       ├─ 開発     … 担当リク(必要になったら増える)
       └─ …
```

## 考え方

### 話しかける相手はショーだけ

「TODO に入れといて」「メモ」「ちょっと相談」など、何でもショーに話しかけます。
ショーが内容を見て、自分で片づけるか、部署のフォルダに書くかを決めます。
あなたが部署を選ぶ必要はありません。

### 部署は、あとから自然に増える

最初にあるのは秘書室だけです。
部署がまだない種類の依頼が2回続くと、ショーが「〇〇部、作っときましょか？」と提案します。
部署には担当キャラクターが付き、その部署のルールに沿って記録が整理されます。

### 記録は全部ファイルに残る

やり取りの結果は、カレントディレクトリの `my-office/` フォルダに Markdown で保存されます。
次の日に話しかけても、ショーは過去のメモや決定事項を読んでから答えます。

## こんな人に向いています

- 個人開発やフリーランスで、タスクやアイデアが散らかりがちな人
- 副業や学業と並行して、少しずつ事業を育てている人
- 調べたことや決めたことを、あとから見返せる形で残したい人

## 動作の前提

- Claude Code が使えること
- 外部サービスとの連携(MCP)は不要です。`my-office/` フォルダのファイルだけで完全に動きます
