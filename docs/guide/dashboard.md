# ダッシュボード

オフィスの様子をブラウザで見渡せる、読み取り専用のダッシュボードです。
`my-office/` のファイルを読むだけで、書き込みはしません。

::: tip ダッシュボードなしでも動きます
「ダッシュボード見せて」とショーに話しかければ、テキスト版の概要がいつでも見られます。
:::

## 起動

`my-office/` があるフォルダ(またはその下のフォルダ)で実行します。

```bash
npx my-office-dashboard
```

ブラウザで `http://localhost:8739` が開きます。
カレントディレクトリから上へたどって `my-office/` を探します。見つからないときは、案内を表示して終了します。

### オプション

| オプション | 説明 |
|---|---|
| `-p, --port <番号>` | ポート番号(既定: 8739) |
| `-d, --dir <パス>` | `my-office/` を探し始める場所(既定: カレントディレクトリ) |
| `--no-open` | ブラウザを自動で開かない |
| `-h, --help` | ヘルプを表示 |
| `-v, --version` | バージョンを表示 |

## 画面

| 画面 | 内容 |
|---|---|
| 概要 | オフィスの全景。オーナー → ショー → 部署の組織図、担当カード、今日の TODO・Inbox の件数、最近の更新 |
| ファイルツリー | `my-office/` のフォルダとファイルの一覧 |
| ネットワーク図 | オフィス → 部署 → サブフォルダのつながり |
| 全文検索 | すべてのメモやファイルを横断して検索 |
| 部署詳細 | 部署のファイル一覧。Markdown のプレビューと生のテキストを切り替えて表示 |

画面の切り替えと、ライト / ダークの切り替えは右上にあります。

担当やオーナーのアイコンには、`my-office/_assets/<部署フォルダ>.png`(オーナーは `owner.png`)の画像が使われます。なければイニシャルの丸になります。

## 概要画面の見かた

| 表示 | 意味 |
|---|---|
| 稼働中 / 最近 / 待機 | その部署のファイルが最後に更新されたのが、10分以内 / 24時間以内 / それより前 |
| 吹き出し | その部署で最後に更新されたファイルの見出し |
| ✓ 納品 | status が completed・published・delivered・paid になった最新のファイル |
| 見出しの「1/3」 | 進行中のファイル数 / ファイル数(秘書室は、今日の未完了 TODO / 今日の TODO) |
| 提案待ち | まだ作っていない部署と、これまでの依頼の回数 |

ファイルが変わると、画面は自動で更新されます。

## 集計に入らないもの

- 各フォルダの `CLAUDE.md`
- 名前が `_` で始まるファイルとフォルダ(`_template.md`、`_assets/` など)
- 部署へ移動済みのメモ(`status: moved`)
