# 秘書との日常

`/sho` のあとに、普段の言葉で話しかけます。「秘書」「ショー」「TODO」「壁打ち」「相談」などの言葉でも呼び出せます。

## TODO

<div class="chat">
  <div class="msg user"><span class="who">あなた</span>明日までにLPのワイヤーを作る、ってTODOに入れといて。優先度は高で</div>
  <div class="msg sho"><span class="who">ショー</span>了解です、任しといてください！今日の TODO の「最優先」に入れときました。<pre>## 最優先
- [ ] LPのワイヤーを作る | 優先度: 高 | 期限: 2026-10-05</pre></div>
</div>

- 保存先: `secretary/todos/YYYY-MM-DD.md`(1日1ファイル)
- 見出しは「最優先」「通常」「余裕があれば」「完了」「メモ・振り返り」の5つ
- 終わったタスクは `- [x] … | 完了: YYYY-MM-DD` になって「完了」へ移ります
- 「今日やること」と聞くと、今日の TODO を見せてくれます

### やり残しの引き継ぎ

その日最初に話しかけると、前回のファイルに残っている未完了の TODO を探して、引き継ぐか聞いてくれます。
引き継いだ行の末尾には `| 繰越: 元の日付` が付きます。

## メモ(Inbox)

<div class="chat">
  <div class="msg user"><span class="who">あなた</span>メモ: 料金プランは3段階がよさそう</div>
  <div class="msg sho"><span class="who">ショー</span>ほな、メモしときました！<pre>- **23:16** | 料金プランは3段階がよさそう</pre></div>
</div>

- 保存先: `secretary/inbox/YYYY-MM-DD.md`
- 時刻つきで1行ずつ追記されます。分類に迷ったものも、まずここに入ります

## 壁打ち・相談

<div class="chat">
  <div class="msg user"><span class="who">あなた</span>アプリ名の候補、ちょっと壁打ちしたい。家計簿で、やさしい感じ。3案くらい出して、まとまったら保存して</div>
  <div class="msg sho"><span class="who">ショー</span>ええですやん、名前決めはワクワクしますね！(3つの案と理由を説明したあと)この壁打ちの内容は secretary/notes/app-name-ideas.md に保存しときました。</div>
</div>

- 保存先: `secretary/notes/トピック名.md`
- 「背景・きっかけ」「議論・思考メモ」「結論・ネクストアクション」の形でまとまります

## テキスト版ダッシュボード

「ダッシュボード見せて」と話しかけると、オフィスの状況をまとめて表示します。

```
┏━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
┃ my-office ダッシュボード  2026-10-04
┣━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
┃ 秘書室(ショー)
┃   今日の TODO: 未完了 1件 / 完了 0件
┃   Inbox: 未整理 1件
┣━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
┃ リサーチ(ミオ)  ファイル 2件
┃   completed 2件
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

ブラウザで見たいときは [ダッシュボード](./dashboard) を使います。

## 言われなくても記録すること

| 内容 | 保存先 |
|---|---|
| 意思決定 | `secretary/notes/YYYY-MM-DD-decisions.md` |
| 学び・気づき | `secretary/notes/YYYY-MM-DD-learnings.md` |
| アイデア | `secretary/inbox/YYYY-MM-DD.md` |

## 記録のルール

- 同じ日付のファイルがあれば追記します(新しく作りません)
- 既存のファイルは上書きしません
- 追記するときは時刻を付けます
