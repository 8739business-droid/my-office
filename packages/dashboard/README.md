# my-office-dashboard

my-office(秘書ショーの仮想オフィス)の組織フォルダ `my-office/` を、ブラウザで見える化するダッシュボードです。

- **読み取り専用**です。組織フォルダには一切書き込みません
- ファイルが変わると、画面がすぐに更新されます
- 外部への通信はしません(フォントもシステムのものを使います)。待ち受けは `127.0.0.1` だけです

## 起動のしかた

`my-office/` があるフォルダ(またはその中)で実行します。

```bash
npx my-office-dashboard
```

ブラウザが自動で開き、`http://localhost:8739` が表示されます。止めるときは `Ctrl+C` です。

`my-office/` が見つからないときは、Claude Code で `/sho` を実行して、初回セットアップをしてください。

## オプション

| オプション | 意味 | 既定 |
|---|---|---|
| `-p, --port <番号>` | 待ち受けるポート | `8739` |
| `-d, --dir <パス>` | `my-office/` を探し始める場所。ここから親へ向かって探します | カレントディレクトリ |
| `--no-open` | ブラウザを自動で開かない | 開く |
| `-h, --help` | ヘルプを表示 | |
| `-v, --version` | バージョンを表示 | |

例:

```bash
npx my-office-dashboard --port 9000 --dir ~/work --no-open
```

組織フォルダとみなすのは、`CLAUDE.md` に「## オーナープロフィール」がある `my-office/` だけです。

## 画面

| 画面 | 内容 |
|---|---|
| 概要 | オーナー → ショー → 部署の組織図。今日の TODO・Inbox・部署ごとの進み具合・提案待ちの部署・最近の更新 |
| ファイル | 組織フォルダのツリーと、ファイルの中身 |
| ネットワーク | 組織フォルダ → 部署 → サブフォルダのつながり |
| 検索 | Markdown ファイルの全文検索(最大30件) |
| 部署詳細 | 概要の担当カードを押すと開きます。ファイル一覧と、プレビュー/生テキストの切り替え |

右上の ☀ / ☾ でライト/ダークを切り替えられます(既定はダーク)。

### 概要の見かた

- **担当の状態**: 部署内の最後の更新が 10分以内=稼働中、24時間以内=最近、それ以外=待機
- **部署見出しの a/b**: 進行中の status のファイル数 / ファイル数。秘書室だけは、今日の未完了 TODO / 今日の TODO 総数
- **吹き出し**: その部署で最後に更新されたファイルの見出し(24時間以内に動いた部署だけ)
- **✓ 納品**: status が completed / published / delivered / paid の最新ファイル
- **提案待ち**: まだ作っていない部署と、部署の提案メモに出てくる部署。依頼の回数つき
- **道具(MCP)**: 案内の表示だけです(接続状態は読みません)

`CLAUDE.md`、名前が `_` で始まるファイルとフォルダは、集計にも表示にも使いません。
設定欄が `status: moved` のファイルは件数に数えません。

### 担当のアイコン

`my-office/_assets/<部署フォルダ>.png`(`.jpg` `.webp` も可)を置くと、その画像がアイコンになります。
なければ名前の最初の1文字の丸になります。`_assets/owner.png` を置くとオーナーのアイコンになります。

## 開発

```bash
cd packages/dashboard
npm install
npm run build                         # 画面をビルド(dist/ に出力)
npm start -- --dir test/fixtures      # ビルドした画面とサーバーを起動
```

画面を手直しするときは、サーバー(`npm start -- --dir test/fixtures --no-open`)を起動したうえで、別の端末で `npm run dev` を実行します。
`/api` は `127.0.0.1:8739` へ中継されます(別のポートなら `MY_OFFICE_API_PORT=18739 npm run dev`)。

テストはリポジトリ直下で実行します。

```bash
cd /path/to/my-office
npx vitest run packages/dashboard
```

### API(すべて GET)

| パス | 内容 |
|---|---|
| `/api/overview` | 概要(オーナー情報・TODO・Inbox・部署の集計・提案待ち・活動ログ・24時間の更新回数) |
| `/api/file?path=` | 組織フォルダ内のファイル(外を指すパスは 403) |
| `/api/department/:id` | 部署の詳細とファイル一覧 |
| `/api/search?q=` | 全文検索(最大30件、一致行の抜粋つき) |
| `/api/tree` | ツリー |
| `/api/activity` | 最近の更新20件 |
| `/api/asset/:folder` | `_assets/<folder>` の画像(なければ 404) |
| `/api/events` | 変更の通知(Server-Sent Events。変更をまとめて `update` を送る) |
